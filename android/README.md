# Kshana on Android

The Android app is a thin Kotlin/Compose shell over the Rust engine. The engine is
compiled per ABI with `cargo-ndk`, and Kotlin bindings are generated by UniFFI from the
`kshana-ffi` crate. No astrology logic is written in Kotlin.

## One-time setup

```sh
rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android
cargo install cargo-ndk
# Android NDK r26+ installed and ANDROID_NDK_HOME set
```

## Build the engine and bindings

```sh
./android/build-engine.sh            # release .so for each ABI + Kotlin bindings
```

Outputs:

- `android/app/src/main/jniLibs/<abi>/libkshana_ffi.so`
- `android/app/src/main/java/uniffi/kshana_ffi/kshana_ffi.kt`

Add `net.java.dev.jna:jna:5.14.0@aar` to the app's dependencies (UniFFI loads the
library through JNA).

## Using it from Kotlin

```kotlin
import uniffi.kshana_ffi.*

val birth = instantFromUtc(UtcFields(1990, 10, 29, 23, 6, 0u, 0u))   // UTC fields
val ay = ayanamsaLahiri(birth)
val p = panchanga(moonTropical = 267.4, sunTropical = 202.1, i = birth)
println("${p.nakshatra} pada ${p.pada}, ${p.tithi}")
```

## Ephemeris data

The app ships `de440s.bsp` (about 32 MB, 1849–2150) inside the APK's assets and opens it
with `Spk.open`. Longer ranges download DE441 on demand. Nothing is computed on a
server.
